# MichiHUD
A custom HUD for Team Fortress 2.

This branch is currently NOT in development. Once the hud has been re-written, this branch is to serve the purpose of providing the old UI which I was going for back when I originally made this repo.
Which is to say what it currently is, just less broken.

# Notice
This hud has *not* been updated since before the Scream Fortress update 2024.
This means a lot of UI elements are broken, due to said update.
Expect to encounter unedited things and expect it not to work quite right.
